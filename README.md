## Systems I Build

### Navdrishti — Student Placement Management Platform

Role-based student placement management platform owned end-to-end. Currently in final development, validation, and rollout.

- Primary technical owner across architecture, planning, development, deployment, and production readiness
- Supabase + PostgreSQL with RBAC and Row Level Security for secure, role-aware data access
- React/TypeScript interfaces, audit logging, and Dockerized multi-environment delivery
- GitHub Actions CI/CD across local, staging, and production on Azure-aligned infrastructure

### BrainPulses — Live Quiz Platform

Production quiz platform maintained through live events, with an active path toward a more maintainable 2.0 architecture.

- Production support through feature work, UI improvements, and client-specific customizations
- Reliably operated large-scale live quiz events under real event pressure
- React + MongoDB stack with Azure Storage for supporting assets
- n8n workflows where operational automation reduces repetitive load; BrainPulses 2.0 architecture prototyped separately

### DISHA — Multi-College PGDM Induction Platform

ASM’s induction platform for PGDM cohorts: QR geofenced attendance, timed quizzes, assessments, and live leaderboards.

- Three-app monorepo: Express/Prisma API with Redis and Socket.IO, plus React student and admin SPAs
- QR + camera attendance with GPS geofence; server-authoritative quizzes and live occupancy/leaderboards
- Multi-college program scoping so cohort data stays isolated across institutions
- Azure Static Web Apps for frontends; VPS API behind Nginx/PM2 with Dockerized Postgres and Redis

### LevelUP — School Assessment Platform

Zapienz LevelUP — timed multi-subject quizzes, AI-assisted grading, and hardened session security for schools.

- API + student SPA + admin SPA with server-enforced wall-clock deadlines and attempt sweepers
- JWT refresh cookies, optional TOTP MFA, trusted devices, and single active session with force-login
- Question banks with nested types, CSV/XLSX import, and Excel reporting for admins
- Objective auto-grade plus optional OpenRouter subjective review with human accountability

### Personal Portfolio Studio — CMS-Driven Portfolio Platform

A production portfolio that is itself a platform: Studio CMS for projects, logos, tech icons, chrome, nav, brand, and SEO — editable without redeploying frontend code.

- Supabase-backed public site with PostgreSQL, RLS, and Storage for content and media
- Authenticated Studio for profile, case studies, technologies, timeline, resume PDFs, inbox, and site config
- Featured flags and incomplete states controlled in admin — editorial, not hardcoded
- Seed pipelines upload local assets into Storage so environments stay reproducible
